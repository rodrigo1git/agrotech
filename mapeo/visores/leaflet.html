Alineación del relevamiento

Mueve juntos cámaras, árboles y líneas en cualquier dirección. Los valores son desplazamientos totales desde el original.

El giro conserva las distancias y mantiene fija la cámara de referencia en su posición corregida. Ángulo positivo: horario.

Para cargar las calles, serví este mapa desde la carpeta del proyecto:

python -m mapeo.servidor_mapa

Abrir mapa en localhost

El archivo local permite usar el plano y las evidencias, pero no solicita calles a OpenStreetMap.

Las posiciones por caja usan supuestos de altura o distancia; no son mediciones. Los grupos violetas pueden contener varios árboles. El total confirmado excluye candidatos y grupos.

Revisión local

Las revisiones se descargan para aplicarlas al inventario. Este archivo no modifica la base de datos.
